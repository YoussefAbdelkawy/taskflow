# User stories

Every story has an ID. Every test that checks a story has the ID in its `describe`, `it` or `test` title, so `npm run trace` can build [TRACEABILITY.md](TRACEABILITY.md) from the test files. Keep the table format: the script reads the first three columns.

Owners: FR1 Nazmy · FR2 Youssef · FR3 Tony · FR4 Fady · FR5 Mostafa · FR6 Ali (Milestone 2) and FR7–FR12 (Milestone 3).

| ID     | FR   | Owner   | Story                                                                                                                                                                | Acceptance criteria                                                                                                          |
| ------ | ---- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| US1-1  | FR1  | Nazmy   | As a project manager, I want to create a task and assign it to a member so that work has an owner.                                                                   | Only managers (403 otherwise); title, due date and priority validated (400); saved as To do                                  |
| US1-2  | FR1  | Nazmy   | As an assignee, I want to change my task's status so that the team sees progress.                                                                                    | New status saved; history entry with old, new, who and when                                                                  |
| US1-3  | FR1  | Nazmy   | As a project manager, I want only the assignee or a manager to change a status so that progress stays trustworthy.                                                   | Anyone else gets 403 and the status is unchanged                                                                             |
| US2-1  | FR2  | Youssef | As a project manager, I want to make a task repeat daily, weekly or monthly so that routine work is created for me.                                                  | Completing an instance creates the next one; the next due date is shown                                                      |
| US2-2  | FR2  | Youssef | As a project manager, I want each period created exactly once so that the board has no duplicates.                                                                   | Repeated checks and restarts never create a second copy                                                                      |
| US2-3  | FR2  | Youssef | As a project manager, I want to turn repeating off so that finished routines stop.                                                                                   | No new copies; the current one stays                                                                                         |
| US3-1  | FR3  | Tony    | As an assignee, I want a notification when a task is assigned to me so that I start on time.                                                                         | Title, project, due date and priority within 5 seconds                                                                       |
| US3-2  | FR3  | Tony    | As an assignee, I want one reminder before a task is due so that I do not miss it.                                                                                   | Exactly one due-soon reminder per task                                                                                       |
| US3-3  | FR3  | Tony    | As an assignee or manager, I want an alert when a task is overdue so that we can react.                                                                              | Assignee and manager alerted; Done tasks get nothing                                                                         |
| US4-1  | FR4  | Fady    | As a team member, I want to comment on a task so that discussion stays with the work.                                                                                | Saved with author and time                                                                                                   |
| US4-2  | FR4  | Fady    | As a team member, I want empty comments rejected so that the thread stays useful.                                                                                    | Whitespace-only content gets 400 and nothing is saved                                                                        |
| US4-3  | FR4  | Fady    | As a project member, I want only members to comment so that outsiders cannot post.                                                                                   | Non-members get 403                                                                                                          |
| US5-1  | FR5  | Mostafa | As a team member, I want to filter my tasks by priority and status so that I see what matters.                                                                       | Only matching tasks                                                                                                          |
| US5-2  | FR5  | Mostafa | As a team member, I want to sort my tasks by due date so that I know what is next.                                                                                   | Earliest or latest first                                                                                                     |
| US5-3  | FR5  | Mostafa | As a team member, I want a clear message when nothing matches so that I know the filter worked.                                                                      | Empty list, "No tasks found"                                                                                                 |
| US6-1  | FR6  | Ali     | As a project manager, I want to say that task B depends on task A so that order is respected.                                                                        | B is blocked while A is not Done                                                                                             |
| US6-2  | FR6  | Ali     | As an assignee, I want my task unblocked when its prerequisite is done so that I can start.                                                                          | B can move to In progress once A is Done                                                                                     |
| US6-3  | FR6  | Ali     | As a project manager, I want cycles rejected so that no task waits forever.                                                                                          | 409/400 and nothing saved                                                                                                    |
| US7-1  | FR7  | Youssef | As a project manager, I want a report per project (tasks by status, completion rate, overdue tasks, workload per member) so that I can see where the project stands. | AC1 only managers (403) · AC2 numbers match the database for the date range · AC3 an empty project shows an empty state      |
| US7-2  | FR7  | Youssef | As a project manager, I want to export the report as CSV so that I can share it with people who do not use TaskFlow.                                                 | AC1 `taskflow-<project>-<yyyy-mm-dd>.csv` · AC2 commas, quotes and new lines escaped · AC3 same columns as the overdue table |
| US7-3  | FR7  | Youssef | As a team member, I want a dashboard with my open, due-this-week and overdue counts and my next tasks so that I know what to do today.                               | AC1 only my tasks · AC2 overdue = before today and not Done · AC3 at most 6 tasks, earliest first                            |
| US8-1  | FR8  | Nazmy   | As a team member, I want a Kanban board per project where I drag a task to another column so that I can update status quickly.                                       | AC1 status rule applies · AC2 blocked cards snap back with a toast · AC3 Undo restores the status                            |
| US8-2  | FR8  | Nazmy   | As a project manager, I want to edit a task's title, description, priority, due date and assignee so that I can correct plans.                                       | AC1 validated like create · AC2 new assignee notified · AC3 members get 403                                                  |
| US8-3  | FR8  | Nazmy   | As a project manager, I want to delete a task after confirming so that mistakes do not clutter the board.                                                            | AC1 confirm names the task · AC2 dependencies, comments and history removed · AC3 dependants unblocked                       |
| US9-1  | FR9  | Ali     | As a team member, I want a project activity feed so that I can see what changed while I was away.                                                                    | AC1 newest first, 20 per page · AC2 who, what, when · AC3 members only                                                       |
| US9-2  | FR9  | Ali     | As a team member, I want to remove a dependency and pick dependencies from a searchable list so that blockers stay accurate.                                         | AC1 DELETE endpoint · AC2 same project, no cycles offered · AC3 manager only                                                 |
| US10-1 | FR10 | Fady    | As a project manager, I want to rename a project, edit its description and remove members so that the project stays current.                                         | AC1 PATCH and DELETE endpoints · AC2 removed member's open tasks unassigned · AC3 last manager cannot be removed             |
| US10-2 | FR10 | Fady    | As a team member, I want a project overview with progress, members and open-task counts so that I understand the project at a glance.                                | AC1 progress = Done / all · AC2 roles shown · AC3 same bar on the projects list                                              |
| US10-3 | FR10 | Fady    | As a commenter, I want to edit or delete my own comment so that I can fix mistakes.                                                                                  | AC1 author only · AC2 "edited" shown · AC3 empty rejected                                                                    |
| US11-1 | FR11 | Mostafa | As a user, I want a command palette (Ctrl/Cmd K) that searches my tasks and projects so that I can jump anywhere fast.                                               | AC1 only accessible items · AC2 grouped, max 8 each · AC3 Enter opens, Esc closes                                            |
| US11-2 | FR11 | Mostafa | As a team member, I want My tasks as a searchable, paginated table whose filters stay in the URL so that I can bookmark a view.                                      | AC1 case-insensitive search · AC2 20 rows per page · AC3 reload keeps filters                                                |
| US12-1 | FR12 | Tony    | As a user, I want to turn each notification type on or off so that I only get alerts I care about.                                                                   | AC1 four types · AC2 muted types not created · AC3 all on by default                                                         |
| US12-2 | FR12 | Tony    | As a user, I want a bell popover with my latest 5 notifications and "Mark all as read" so that I can clear alerts without leaving the page.                          | AC1 PATCH read-all · AC2 count refreshes within 10 s · AC3 click opens the task                                              |
| US12-3 | FR12 | Tony    | As an assignee, I want a notification when someone comments on my task so that I can respond.                                                                        | AC1 not for my own comments · AC2 respects US12-1 · AC3 includes the commenter's name                                        |
